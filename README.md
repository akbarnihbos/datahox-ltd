# DATAHOX LTD — Landing Page

Next.js 14 (App Router) + Tailwind CSS + TypeScript.

## Jalankan
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Struktur
- `app/` — layout (font Bodoni Moda + Manrope), halaman, CSS global
- `components/` — Navbar, Hero, HowItWorks (slider horizontal digerakkan scroll), WorkAnywhere (phone ter-scroll), Footer
- `lib/content.ts` — teks navigasi, footer, email (GANTI `hello@datahox.com` dengan email resmi)
- `public/logo.png` — logo asli | `public/logo-light.png` — versi untuk latar gelap (wordmark putih)
